## فایل‌های این بسته

1. `app/universities/[slug]/page.tsx` — جایگزین فایل فعلی شود.
2. `lib/semantic-labels.ts` — فایل جدید است و باید اضافه شود.

## چه چیزی تغییر می‌کند؟

- URLهای متفاوت حذف نمی‌شوند.
- dedupe واقعی همچنان بر اساس URL canonical انجام می‌شود؛ نسخه‌های واقعاً تکراری یک منبع ادغام می‌شوند.
- عنوان خام داده‌ها دست‌کاری نمی‌شود؛ فقط عنوان نمایشی در UI ساخته می‌شود.
- عنوان نمایشی شماره‌گذاری مصنوعی ندارد.
- برای اسناد مستقیم، نوع فایل مثل PDF/Word/Excel در عنوان می‌آید.
- برای مسیرهای سامانه، کتابخانه، آزمایشگاه، نشریات، طرح‌های پژوهشی، ورود به سامانه، مقررات و ... عنوان معنایی ساخته می‌شود.
- اگر یک پرتال هم URL خوانا و هم مسیر `index.php?...` برای همان صفحه داشته باشد، URL مبهم می‌تواند عنوان محتوایی را از همتای خوانای همان مسیر بگیرد، ولی هر دو لینک حفظ می‌شوند.
- اگر دو عنوان هنوز یکسان باشند، زمینه واقعی URL (مسیر/بخش/دامنه) برای تفکیک نمایش داده می‌شود؛ شماره مصنوعی ساخته نمی‌شود.

## چه چیزی تغییر نمی‌کند؟

- هیچ فایل JSON داده بازنویسی نمی‌شود.
- crawler تغییر نمی‌کند.
- checkpoint/resume تغییر نمی‌کند.
- `prepare:data` لازم نیست.
- Crawl مجدد لازم نیست.

## فایل حذفی

هیچ فایلی نباید حذف شود.

به‌خصوص `data/crawl-checkpoints` را حذف نکنید؛ این بسته ارتباطی با checkpointهای Crawl ندارد.

## اعمال بسته

فایل‌ها را با همین ساختار در ریشه پروژه کپی کنید. سپس:

```bash
npm run typecheck
npm run lint
npm run build
```

اگر هر سه موفق بودند:

```bash
git add "app/universities/[slug]/page.tsx" "lib/semantic-labels.ts"
git commit -m "feat(ui): add semantic labels for distinct evidence links"
git push origin main
```
