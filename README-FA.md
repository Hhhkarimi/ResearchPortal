# Research document scope v2

این بسته جایگزین فیلتر قبلی اسناد نامرتبط است.

## علت ایراد قبلی

نسخه 1 فقط blacklist بود. بنابراین عنوان‌هایی مثل:

- شرایط عمومی و آموزشی
- شرایط ضمانت
- فرم مشخصات دانشجویان
- سند تعهدنامه دانشجویی

در صورتی که عبارت‌هایی مثل «وام» یا «خوابگاه» مستقیماً در همان رکورد نبودند، ممکن بود باقی بمانند.

## سیاست جدید

برای رکوردهای `research-deep-discovery`:

1. ابتدا موارد دانشجویی/آموزشی/رفاهی صریح رد می‌شوند.
2. سپس برای باقی‌ماندن در بخش اسناد، باید یکی از این‌ها وجود داشته باشد:
   - نشانه صریح پژوهش/فناوری/صنعت/نوآوری/پایان‌نامه/گرنت و...
   - زمینه آزمایشگاه پژوهشی
   - زمینه کتابخانه و منابع علمی
   - نشریات و انتشارات علمی
   - قرار داشتن در مسیر پرتال پژوهشی مستقیم و معتبر همان دانشگاه
3. اگر ارتباط پژوهشی اثبات نشود، رکورد از «اسناد پژوهش و فناوری» حذف می‌شود.

رکوردهای curated قدیمی بدون دلیل حذف نمی‌شوند؛ فقط اسناد crawler به Evidence مثبت نیاز دارند.

## نمونه تربت جام

این بسته باید موارد زیر را حذف کند:

- شرایط عمومی و آموزشی — 4.pdf
- سند تعهد نامه دانشجویی — 5.pdf
- شرایط ضمانت — 6.pdf
- شرایط ضمانت - تعداد ضامنین — 7.pdf
- فرم مشخصات دانشجویان روزانه/شبانه
- وام‌های دانشجویی
- ثبت‌نام پذیرفته‌شدگان
- اطلاعیه خوابگاه
- فایل‌های غذا
- برنامه امتحانات
- چارت درسی
- تجهیزات آموزشی آزمایشگاه

و موارد پژوهشی/پشتیبان پژوهش مثل این‌ها را نگه دارد:

- تجهیزات پژوهشی آزمایشگاه
- اسناد مسیر lab (مگر اینکه صریحاً آموزشی باشند)
- منابع علمی Springer / IEEE / IranDoc / SID
- راهنمای جستجوی کتابخانه
- نشریات علمی
- اسناد صنعت/فناوری با شاهد معنایی واقعی

## فایل‌های جایگزین

- scripts/research-document-scope.mjs
- scripts/filter-research-documents.mjs
- scripts/validate-research-document-scope.mjs

`package.json` فعلی پروژه نیاز به تغییر ندارد؛ pipeline قبلاً این فیلتر را اجرا می‌کند.

## اجرا

بعد از جایگزینی فایل‌ها:

```bash
node --check scripts/research-document-scope.mjs
node --check scripts/filter-research-documents.mjs
node --check scripts/validate-research-document-scope.mjs

npm run filter:research-documents
npm run release:check
npm run typecheck
npm run lint
npm run build
```

Crawler را اجرا نکنید.

گزارش حذف‌ها در این فایل ساخته می‌شود:

`data/generated/research-document-filter-report.json`

برای بررسی تربت جام می‌توانید در گزارش `torbat-jam-agri` را جستجو کنید.
