# Branding + 115-first UI patch

این بسته دو سیاست نمایشی را اعمال می‌کند:

1. عبارت اصلی «پرتال پژوهش دانشگاه‌ها» به «پرتال معاونت پژوهشی و فناوری دانشگاه‌ها» تغییر می‌کند.
2. عدد اصلی تجربه کاربر ۱۱۵ است؛ ۸۰۵ در رادار صفحه اول نمایش داده نمی‌شود.

## مهم‌ترین تغییر
مرکز رادار صفحه اول:
- قبل: ۸۰۵ outcome
- بعد: ۱۱۵ دانشگاه و مؤسسه ISC

۸۰۵ از مدل داده حذف نشده و در صفحات فنی Evidence/Dataset می‌تواند باقی بماند.
